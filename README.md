# Cat Assemble

เกม idle แนวนอนบนเว็บ (PWA) ตัวเราเดินล่ามอนสเตอร์บนแผนที่หลายชั้น ทีมแมวจากกาชาลอยตามช่วยตี ติดตั้งลงมือถือได้และเล่นออฟไลน์ได้

## เล่นในเครื่อง

```bash
python3 -m http.server 5173
```

แล้วเปิด http://localhost:5173 (ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิกไฟล์ตรงๆ จะใช้ไม่ได้)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `styles.css` | หน้าจอเกม |
| `src/config.js` | ตัวเลขสมดุลเกมทั้งหมด แมว สกิล โซน |
| `src/game.js` | กลไกเกม: ดาเมจ ด่าน บอส การซื้อ สกิล |
| `src/arena.js` | ด่านเนื้อเรื่อง (ต้นแบบ): จัดทีม 5 ตัวบนกระดาน 3×3 แล้วสู้อัตโนมัติ |
| `src/audio.js` | เสียงทั้งหมด สังเคราะห์ด้วย Web Audio (เอฟเฟกต์และเพลงชิปทูนตามแผนที่) |
| `src/battle.js` | ฉากต่อสู้บน canvas: แท่น การเดิน/กระโดด มอนสเตอร์ แมวช่วยตี |
| `src/main.js` | หน้าจอ เมนู กาชา และเชื่อมทุกส่วนเข้าด้วยกัน |
| `src/state.js` | เซฟ/โหลด สำรองและกู้เซฟ |
| `sw.js`, `manifest.webmanifest` | PWA: ติดตั้งลงเครื่องและเล่นออฟไลน์ |

## อัปเดตเกม

เมื่อเพิ่มไฟล์ใหม่ ให้ใส่ชื่อไฟล์ในรายการ `SHELL` ของ `sw.js` และเปลี่ยนเลข `CACHE` เพื่อให้ผู้เล่นได้ไฟล์ใหม่

## ลิขสิทธิ์

สงวนลิขสิทธิ์ทั้งโค้ดและภาพ ห้ามนำไปใช้ซ้ำโดยไม่ได้รับอนุญาต
